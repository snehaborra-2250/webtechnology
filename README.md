## Project

### Design Theme
The website uses a warm notebook/paper-inspired theme with bold borders, handwritten-style academic presentation, and orange/teal/yellow accents.
This project contains separate HTML files for the practical programs. The dashboard is `index.html`.

## How to run
1. Open the `practical-programs` folder in VS Code.
2. Open `index.html`.
3. You can open it directly in a browser or use the Live Server extension.
4. Navigate through the dashboard and program-list pages.

## Structure
- `html/` — HTML practicals
- `css/` — CSS practicals
- `javascript/` — core JavaScript, DOM, Events, Forms, Browser, Storage and Mini Projects
- `assets.css` — common styling
